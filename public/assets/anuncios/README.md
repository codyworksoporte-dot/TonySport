# Imágenes de los anuncios del inicio

Subí aquí una foto horizontal, preferiblemente WebP, con uno de estos nombres. También se admiten JPG, JPEG y PNG. La siguiente publicación la mostrará automáticamente. El sitio presenta el texto y el botón de cada anuncio mientras falta su imagen.

| Nombre sin extensión | Anuncio |
| --- | --- |
| black-friday | Black Friday |
| portero | Uniforme de portero y gafete |
| premios | Puntos de la App Tony |
| domicilio | Servicio a domicilio |
| personalizados | Uniformes personalizados |
| replicas | Catálogo de réplicas |
| tiendas | Tiendas Tony |
| forma-configurador | Tarjeta «Creá tu pedido» |
| forma-tienda | Tarjeta «Comprá en tienda» |
| forma-promociones | Tarjeta «Promociones Tony» |
| app-tony | Franja de descarga de la app |
| tienda-38313 | Réplicas bordadas de $10.99 |
| tienda-38248 | Réplicas bordadas de $8.49 |
| tienda-38223 | Creá tu pedido en la tienda |

Usá un encuadre con el producto en el centro. La web coloca el título y el botón por separado. Los textos y destinos están en `lib/home-campaigns.ts`. La portada grande de Black Friday conserva su arte original.
